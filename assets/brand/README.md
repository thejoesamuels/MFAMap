# MFAMap brand

MFAMap is a joelabs project. The logo is the joelabs fingerprint loop cut to a map pin, sending out a ping.

| File | Use |
|---|---|
| `readme-banner-dark.png`, `readme-banner-light.png` | README header (picked by the reader's GitHub theme) |
| `social-preview-1280x640.png` | GitHub repo social preview (Settings > General > Social preview) |
| `mfamap-horizontal-dark.svg`, `mfamap-horizontal-light.svg` | Logo with "a joelabs project", for dark and light grounds |
| `mfamap-icon.svg` | Icon on its grey tile |
| `mfamap-icon-transparent.svg` | Yellow icon, transparent, for dark grounds only |
| `header-logo.svg` | The report header logo (inlined in `code/MFAMap.ps1`) |
| `favicon.svg` | The report's browser tab icon (inlined in `code/MFAMap.ps1`, base64) |

## Colour

| Token | Hex | Use |
|---|---|---|
| Brand grey | `#26272A` | Page ground |
| Surface | `#2F3034` | Cards, tables, header |
| Surface high | `#3A3B40` | Progress tracks, raised elements |
| Brand yellow | `#FFC83D` | Logo, accents, coverage |
| Text muted | `#A9AAB0` | Secondary text |
| Text dim | `#85868D` | Labels, timestamps |
| Enrolled | `#7CD591` | Complete, registered |
| Partial | `#E88B0E` | Partial, legacy only |
| Not registered | `#F56A7E` | Not registered, no methods, lapsed |
| Modern | `#6DABDF` | Modern methods (full method audit) |

Status colours always come with a label, and yellow is never a status.

## Rules

- On dark: yellow mark, "MFA" white, "Map" yellow. On light or yellow: everything in brand grey.
- Never yellow on white or light grey (1.5:1, unreadable).
- Use the compact logo (no "a joelabs project") under 64px tall, and put "a joelabs project" in the footer instead.
- Don't redraw, recolour, stretch or add effects to the logo. The full brand guidelines live in the MFAMap brand pack.
